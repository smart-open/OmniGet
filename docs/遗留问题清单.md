## 发布阻塞类

### 1. 🔴 ~~sidecar 三平台生产链路空缺~~ [已修复 2026-09-30]
- **现状**：新增 `scripts/fetch-sidecars.mjs`（官方/高星发布源下载 aria2c / yt-dlp / ffmpeg / ffprobe 到 `resources/engines/<platform>-<arch>/`，已存在的跳过）；CI（build.yml）打包前自动执行收集，Verify sidecars 从 warning 升级为 **fail 门禁**，杜绝"零引擎安装包"静默出包。
- **关联文件**：`scripts/fetch-sidecars.mjs`、`.github/workflows/build.yml`

### 2. 🔴 macOS 签名与公证未配置（代码侧已就绪，等待证书）
- **现状**：`electron-builder.yml` mac 段已加 `identity` / `notarize` / `hardenedRuntime` / `entitlements` **注释化占位**——接入 Apple 证书后在 CI 注入环境变量并取消注释即可，缺证书时构建不受影响。
- **待办**（外部资源，无法本地完成）：
  - [ ] Apple Developer 账号 + 证书接入 CI（`CSC_LINK` / `CSC_KEY_PASSWORD` / `APPLE_ID` / `APPLE_APP_SPECIFIC_PASSWORD` / `APPLE_TEAM_ID`）
  - [ ] 取消 yml 注释 + 提供 `build/entitlements.mac.plist`
- **备注**：Windows 侧 `signAndEditExecutable: false`（无符号链接特权时 winCodeSign 缓存解压失败）——CI 上可开启以恢复 exe 图标/版本信息印刻，见 yml 内注释。
- **无证书分发口径（2026-10-01 确认：暂无 Apple 开发者账号）**：mac 产物为未签名 dmg——用户首次打开需右键 →「打开」，或执行 `xattr -cr /Applications/OmniGet.app` 绕过 Gatekeeper；应用自身已实现 TOFU 引擎指纹校验，未签名不影响运行时安全闸门。

### 3. 🟠 ~~publish 仓库指向确认~~ [已修复 2026-10-01]
- **现状**：`package.json` repository 已设为 `https://github.com/smart-open/OmniGet.git`——electron-updater 据此获取 `app-update.yml` / latest 元数据；Linux 手动更新通道的版本比对与 Releases 直跳也随之生效。
- **备注**：首次发布前需在 GitHub 创建对应 release（electron-updater 拉不到 latest 元数据时会静默跳过，不报错）。

### 4. 🟠 ~~Linux 自动更新通道~~ [已修复 2026-10-01]
- **现状**：Linux 明确"手动更新"口径——`app-updater` 在 Linux 跳过 electron-updater；设置 → 更新 新增「检查新版本」（GitHub latest release 版本比对，`resolveRepoSlug()` 从 package.json repository 解析）+ 发现新版时「前往下载」直开 Releases 页（主进程校验 https 后 openExternal）。同时顺带修复了渲染层残留的废弃 `checkAppUpdate` 桥方法（原指向不存在的 `app:update` 通道）。
- **前置依赖**：#3 配置 repository 字段后版本比对才能命中真实仓库。

## 功能完善类

### 5. 🟠 ~~BT 端口连通性诊断~~ [已修复 2026-09-30，2026-10-01 增强外网探测]
- **现状**：设置 → Tracker 区「BT 端口自检」（IPC `diag:btPort` 检测 6881 本地 TCP 监听）+「外网可达性检测」（`diag:btExternal`：ipify/ifconfig.me 多源获取公网 IP → check-host.net 多节点 TCP 探测，opt-in 且 UI 明示第三方服务与隐私口径）。
